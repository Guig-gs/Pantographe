Installation
============
Pour installer et exécuter le projet Pantographe, suivez les étapes ci-dessous :

1. Clonez le dépôt :
   .. code-block:: bash

      git clone git@github.com:Guig-gs/Pantographe.git

2. Installez les dépendances :
   .. code-block:: bash

      pip install -r requirements.txt

.. note::
   Sous WSL, utilisez ``sudo apt install python3-pip`` avant d'installer les dépendances.
